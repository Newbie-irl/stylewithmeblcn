# StyleWithMeBLCN Inventory Management System

Frontend milestone implementation based on the approved Figma dashboard.

## Technology
- HTML5
- CSS3
- Vanilla JavaScript

## Implemented
- Dashboard homepage
- Sidebar navigation
- Manage Product page
- Manage Inventory page
- Low Stock Alert page
- Out of Stock page
- Reusable statistic cards, panels, navigation, tables, badges and buttons
- Basic product search interaction
- Responsive layout for smaller screens

## Setup
No installation is required.

1. Download/clone the repository.
2. Open `index.html` in a browser.
3. Use the sidebar to navigate between pages.

## Project Description
StyleWithMeBLCN is an inventory management interface for managing pants/products, stock quantities, low-stock alerts, and out-of-stock products.

> Note: This milestone is frontend-only. Database/backend functionality can be connected in later milestones.
